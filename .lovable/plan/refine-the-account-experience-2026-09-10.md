# Refine the account experience

## Scope
Polish the existing signed-in account screens without changing their behavior, data, or navigation.

## Changes
- Refine the shared account frame with a clearer active state, cleaner profile area, improved page headings, and safer mobile spacing around the bottom navigation.
- Improve Trips with a more compact segmented view, better image and booking-detail hierarchy, aligned pricing, and mobile actions that remain easy to tap.
- Improve Favourites and Profile spacing so cards and settings feel consistent across phone, tablet, and desktop widths.
- Polish Messages with softer panel separation, stronger selected/unread states, better message widths, and a composer that stays usable on narrow screens.
- Apply small consistency improvements to host account panels where shared account styling affects them.

## Technical details
- Reuse existing semantic colors, typography, Button components, and translations.
- Keep all mock booking, messaging, profile, and host interactions unchanged.
- Verify the account routes at desktop and mobile sizes, checking overflow, text wrapping, and action placement.
