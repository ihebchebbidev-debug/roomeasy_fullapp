# Haven & Home

Build a polished, responsive vacation-stay booking marketplace inspired by the attached reference screenshots. Use original branding (not Airbnb/DeliBook), but closely follow their visual direction: soft blue/gray photography-led hero, white rounded panels, black typography, vivid lime accents, spacious cards, and the same homepage information hierarchy. Generate original hospitality/property imagery as project assets with AI and use it throughout. Create a scalable, clean future-ready file structure and implement full English/French localization with a prominent language selector. Include: header, hero with destination/date/guests search, category tabs, property card grid, feature/value section, visual award/promo section with booking card overlay, testimonials, responsive mobile UI, and all needed interaction states. Enable Lovable Cloud if needed for future saved favorites/search state, but focus on a complete front-end experience now.
